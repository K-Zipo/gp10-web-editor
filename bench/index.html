GP-10 SysEx Bench

Web MIDIでBOSS GP-10とのSysEx通信を確認する接続テストツール（RQ1は読み出しのみ） 未接続

1. 環境とMIDIアクセス

    ChromeかEdgeで開いてください。SafariはWeb MIDI非対応です。GP-10はドライバの導入が必要です。

    2. ポート

    「GP-10 DAW CTRL」ではなく「GP-10」を選びます。名前に GP-10 を含むポートは自動で選ばれます。

    3. Identity Request

    —

    返事が来れば、ケーブル・ドライバ・MIDI経路は生きています。

    4. Roland ヘッダ設定

    GP-10 は Device ID 10、Model ID 00 00 00 05 で実機応答を確認済みです（Identity返信のファミリーコード 05 03 とも一致）。Device ID 10 は工場出荷時の値です。

    5. RQ1（データ要求）

    —

    返ってきたDT1のアドレス・データ・チェックサム検証・ASCII表示（パッチ名の確認用）を表示します。

    6. アドレススキャン（RQ1・読み出しのみ）

    アドレスサイズデータ（先頭）ASCII

    7. 手入力SysEx

    —

    チェックサムは F0 41 [Dev] [Model] [Cmd] の後ろからを対象に計算します（Model ID の長さはヘッダ設定に従います）。DT1(12)を送ると本体の設定が書き換わるので注意してください。

    8. ダンプと差分（パラメータ位置の特定用）

    ダンプ（黄色＝直前の読み出しから変化、下線＝一度でも変化）

    —

    変化したバイト（新しい順）

    時刻アドレスブロック+位置前→後名前

    使い方: 読み出す → GP-10でつまみを1つ動かす → もう一度読み出す。前回と違うバイトが黄色になり、右の表に残ります。「1秒ごとに繰り返す」をオンにすると、つまみを回しながら変化を追えます。返ってきたDT1はパケットごとに「ブロック」として表示し、アドレスはRolandの7ビット計算で表示します。

    9. アドレスマップ（ラベル）

    アドレス名前長さ現在値観測した範囲

    変化表の「名前」欄に入力しても登録されます。ラベルを付けたバイトは、ダンプ上で青枠になり、マウスを乗せると名前が出ます。現在値と観測範囲は、8で読み出すたびに更新されます。マップはこのブラウザに保存されます。
