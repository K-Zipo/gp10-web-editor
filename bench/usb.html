GP-10 USB probe

Checks whether a browser could talk to the GP-10 directly over USB (WebUSB), without the BOSS driver. Step 1 only reads the USB descriptors. Step 2 sends one identity request, the same harmless “who are you” message the editor sends when it connects.

1. Read the USB layout

2. Try MIDI over USB

Claims the interface found in step 1 and sends an identity request as USB-MIDI packets. If the BOSS driver is installed, the system usually owns the interface and this step fails with “Unable to claim interface”. That does not mean WebUSB is impossible, only that the driver got there first.

Report

Where to run this

  1. Chrome or Edge on a Mac or Windows PC with the BOSS driver: shows the layout, step 2 will most likely be blocked by the driver.
  2. Chrome on Android with a USB OTG cable: the real test, because there is no driver there.
  3. Chrome on a computer without the BOSS driver, or on Linux: also a real test.

iPhone and iPad browsers do not support WebUSB.
